# Doneo

Трекер задач на **React + Vite** с серверной авторизацией (Express), тремя
языками интерфейса, тёмной и светлой темами, drag-and-drop сортировкой и
экспортом в **CSV** и **JSON**.

Приложение работает в двух режимах и переключается между ними автоматически:

- **серверный** — если отвечает Express API, аккаунты и задачи хранятся на
  сервере в JSON-базе (пароли — scrypt-хэши с солью);
- **локальный** — если API недоступно, всё хранится в `localStorage` браузера
  (пароли — SHA-256 с солью).

Текущий режим всегда виден в шапке: бейдж **«Сервер»** или **«Локально»**.

## Возможности

### Языки: uz / ru / eng

- Переключатель **UZ / RU / EN** в шапке и на экране входа, плюс список языков
  на странице «Настройки».
- Переводятся интерфейс, даты, статусы/приоритеты и заголовки CSV; примеры-задачи
  для нового аккаунта создаются на языке интерфейса.
- Выбор сохраняется в `doneo.lang`; при первом запуске учитывается язык браузера
  (fallback — русский), атрибут `<html lang>` обновляется на лету.
- Ошибки приходят с сервера с кодом (`email_taken`, `password_wrong` и т.д.) и
  переводятся на клиенте — поэтому сервер не дублирует все языки.

### Страницы

| Маршрут      | Страница      | Что внутри                                                        |
| ------------ | ------------- | ----------------------------------------------------------------- |
| `#/tasks`    | Задачи        | Форма, фильтры, поиск, сортировка, список, drag-and-drop, экспорт |
| `#/stats`    | Статистика    | Сводка по статусам, приоритетам, дедлайнам и прогресс              |
| `#/settings` | Настройки     | Тема, язык, режим хранения, аккаунт, экспорт, опасная зона        |
| `#/help`     | Справка       | Возможности, страницы, горячие клавиши, хранение данных, API      |

Навигация — на хэш-маршрутах (`src/router/index.jsx`): работает без серверных
rewrite-правил, поддерживает «назад/вперёд» и прямые ссылки вида `/#/settings`.

### Задачи и оформление

- 🔐 Авторизация: регистрация, вход, «Войти как гость», «Запомнить меня».
- 🧩 Автоопределение режима сервер/локально по `GET /api/health`.
- ➕ Добавление, ✏️ редактирование и 🗑 удаление задач.
- 📌 Статусы: To Do / In Progress / Done.
- 🚩 Приоритеты: низкий / средний / высокий.
- 📅 Дедлайн, сортировка по дате (плюс по приоритету, названию, дате создания).
- 🔍 Поиск по названию и описанию, фильтры по статусу и приоритету.
- 🖐 **Drag-and-drop сортировка** — режим «Своя сортировка»: перетаскивание
  карточек за ⠿ и кнопки ↑ ↓ (работают на тач-устройствах и с клавиатуры).
- 📊 Счётчики активных/выполненных задач и прогресс-бар.
- 🌗 **Тёмная и светлая тема** — переключатель в шапке и в настройках.
- ⭳ Экспорт в **CSV** (корректная кириллица в Excel) и **JSON**: отфильтрованного
  списка — на странице «Задачи», всего списка — в «Настройках».
- 📱 Адаптивная вёрстка, карточки, hover-эффекты и анимации.

## Быстрый старт

```bash
npm install
npm run dev:all      # Vite на :5173 и Express API на :4000
```

Открыть http://localhost:5173 — приложение само определит доступность API
(`GET /api/health` → `{"ok":true,"service":"doneo-api"}`).

Полезные команды:

```bash
npm run dev          # только фронтенд (работает в локальном режиме)
npm run dev:server   # только Express API (node server/index.js)
npm run build        # сборка фронтенда в dist/
npm run preview      # предпросмотр сборки на :4173
npm start            # API как самостоятельный процесс (порт из PORT)
```

> Требуется Node.js 18+ (используются `node:crypto`, ESM и `fetch`).
> Если Node не установлен глобально:
> `export PATH="$HOME/.local/node-v24.21.0-darwin-arm64/bin:$PATH"`.

## API

| Метод   | Пух                         | Назначение                                  |
| ------- | --------------------------- | ------------------------------------------- |
| `GET`   | `/api/health`               | проверка доступности (`service: doneo-api`)  |
| `POST`  | `/api/auth/register`        | регистрация (`name`, `email`, `password`, `lang`) |
| `POST`  | `/api/auth/login`           | вход (`email`, `password`)                   |
| `POST`  | `/api/auth/guest`           | гостевая сессия (`lang`)                     |
| `GET`   | `/api/auth/me`              | текущий пользователь (Bearer-токен)          |
| `POST`  | `/api/auth/logout`          | выход (удаляет сессию и гостевые данные)     |
| `GET`   | `/api/tasks`                | список задач пользователя                    |
| `POST`  | `/api/tasks`                | создать задачу                               |
| `PUT`   | `/api/tasks/:id`            | обновить задачу                              |
| `DELETE`| `/api/tasks/:id`            | удалить задачу                               |
| `POST`  | `/api/tasks/clear-completed`| удалить все выполненные                      |
| `PUT`   | `/api/tasks/reorder`        | сохранить порядок (`{ ids: [...] }`)         |
| `GET`   | `/api/sms/settings`         | настройки SMS пользователя                     |
| `PUT`   | `/api/sms/settings`         | номер, включение, время предупреждения        |
| `POST`  | `/api/sms/test`             | отправить тестовое SMS                          |
| `GET`   | `/api/billing/plans`        | каталог тарифов (без входа)                     |
| `GET`   | `/api/billing/subscription`  | текущая подписка                                 |
| `POST`  | `/api/billing/checkout`      | оформить подписку (`tierId`, `periodId`)         |
| `POST`  | `/api/billing/cancel`        | отменить подписку в конце периода                |
| `GET`   | `/api/ai/providers`          | список AI-провайдеров и наличие ключей           |
| `POST`  | `/api/ai/advice`            | совет AI (`question`, `providerId`)              |

Ошибки возвращаются как `{ "error": "…", "code": "…" }`; клиент переводит `code`
на текущий язык.

## Хранение в браузере

Ключи с префиксом `doneo.`: `doneo.tasks.<userId>`, `doneo.users`,
`doneo.session`, `doneo.token`, `doneo.theme`, `doneo.lang`. Данные старой
версии (`tt.*`) автоматически переносятся в новые при первом запуске, а хэш
локального пароля дополнительно проверяется со старой солью — поэтому ранее
созданные локальные аккаунты продолжают работать.

### Подписки: Plus, Pro, Ultima

| | 1 месяц | 6 месяцев | 1 год | Пробный период |
| --- | --- | --- | --- | --- |
| 💎 **Plus** | $1.49 | $6.99 (−22%, $1.17/мес) | $11.99 (−33%, **$1.00/мес**) 🏅 *Самый выгодный* | 5 дней |
| 🚀 **Pro** | $2.99 | $14.99 (−16%, $2.50/мес) | $24.99 (−30%, $2.08/мес) 🏅 *Популярный* | 7 дней |
| 👑 **Ultima** | $4.99 | $24.99 (−17%, $4.17/мес) | $39.99 (−33%, $3.33/мес) 🏅 *Максимум возможностей* | 10 дней |

- Страница `#/pricing`: переключатель периода (по умолчанию **год** — самый выгодный),
  цена, зачёркнутая обычная цена, скидка, экономия, цена за месяц и кнопка
  **«Попробовать бесплатно»**.
- Перед стартом пробного периода карточка явно показывает стоимость после него:
  «После пробного периода: $11.99 за 1 год».
- После триала подписка автоматически переходит на выбранный платный период.
- Функции: **Plus** — задачи, календарь, напоминания, категории, приоритеты, базовые
  темы. **Pro** — всё из Plus + повторяющиеся задачи, расширенный календарь, умные
  напоминания, статистика, шаблоны, расширенный поиск, доп. темы, синхронизация.
  **Ultima** — всё из Pro + AI-помощник, AI-планирование дня, авто-приоритеты,
  планирование недели, цели, расширенная аналитика, экспорт, совместные задачи,
  эксклюзивные темы.
- ⚠️ **Реальной оплаты нет**: `POST /api/billing/checkout` активирует подписку сразу и
  помечает её `demo: true`. Для боевого режима замените эту функцию на платёжный
  провайдер (Stripe/Paddle) — остальная логика (триал → оплата → истечение) готова.

### AI-помощник (тариф Ultima)

- Страница `#/ai`: выбор источника **ChatGPT / Grok / Gemini**, вопрос, ответ.
- Ключи API читаются только на сервере: `OPENAI_API_KEY`, `XAI_API_KEY`, `GEMINI_API_KEY`.
- Без ключей, без интернета или при ошибке провайдера показываются **офлайн-советы**
  на языке пользователя — вместо ошибки. AI отвечает советами и подсказками,
  другие источники данных не используются.

### Офлайн-режим

- При потере сети появляется компактная карточка: облако Doneo с перечёркнутым
  Wi-Fi (анимация), кнопка «🔄 Повторить подключение» и подпись
  «Doneo работает и без интернета 💙».
- Приложение при этом **остаётся рабочим**: задачи доступны, изменения сохраняются
  локально и уходят на сервер после восстановления связи.
- Код внизу карточки: `&/ERR_CONNECTION_RESET / NETWORK_ERROR 503-ERR_CODE`.

### SMS-напоминания

- ✉️ Если до дедлайна задачи осталось мало времени, сервер отправляет **одно SMS**
  на номер пользователя. Настройки — в разделе «SMS-уведомления» на странице
  «Настройки»: номер, тумблер включения и «напомнить за 10 минут / 30 минут /
  1 час / 3 часа / 1 день / 7 дней».
- Сервер проверяет дедлайны раз в минуту и запоминает `smsSentAt`, поэтому
  повторных SMS не бывает. Гостевые аккаунты не получают напоминаний.
- Текст SMS приходит на языке, выбранном при регистрации (ru / en / uz).
- Номер хранится только в базе на сервере (`server/data/db.json`) и в API
  возвращается замаскированным: `*********4567`.
- Кнопка «Отправить тестовое SMS» подтверждает номер.

**Провайдеры** выбираются переменной окружения `SMS_PROVIDER` (см. `.env.example`):

| Провайдер | Переменные | Примечание |
| --- | --- | --- |
| `console` | — | по умолчанию: SMS пишется в лог сервера, реально не отправляется |
| `twilio` | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` | Twilio REST API, Basic-авторизация |
| `smsru` | `SMSRU_API_ID` | SMS.ru, `status: 0` — успех |

```bash
# проверить отправку без реальных денег
SMS_PROVIDER=console npm run dev:all
tail -f /tmp/dev_all.log | grep '\[sms'

# реальная отправка
SMS_PROVIDER=smsru SMSRU_API_ID=ваш-id npm run dev:all
```

Ключи провайдера читаются **только на сервере** и никогда не попадают в браузер;
файл `.env` добавлен в `.gitignore`. Если провайдер не настроен, панель в
настройках покажет предупреждение, а отправка вернёт `sms_not_configured`.

## Переменные окружения

- `PORT` — порт API (по умолчанию 4000).
- `VITE_API_URL` — базовый URL API на клиенте (по умолчанию `/api`).
- `SMS_PROVIDER`, `TWILIO_*`, `SMSRU_API_ID` — см. раздел про SMS выше.

## Заметки по безопасности

- В серверном режиме пароли хешируются через `crypto.scryptSync` со случайной
  солью, сессии — случайные 32-байтные токены в заголовке `Authorization: Bearer`.
- В локальном режиме (без сервера) пароли хешируются (SHA-256) в браузере и
  хранятся в `localStorage` — это **демонстрационный** вариант и он не заменяет
  серверную аутентификацию.
- Файл `server/data/db.json` содержит данные всех пользователей: не коммитьте
  его (каталог добавлен в `.gitignore`).
- CORS открыт для удобства локальной разработки — для продакшена ограничьте
  список разрешённых origin. Также стоит вынести хранилище из JSON-файла в
  настоящую БД и добавить срок жизни сессий.
